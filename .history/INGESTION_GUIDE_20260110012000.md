## 1. Khởi động Container với GPU

### 1.1 Sử dụng Docker Compose GPU
```bash
# Dừng tất cả containers hiện tại
docker compose down

# Khởi động với GPU support
docker compose -f docker-compose_gpu.yml up -d

# Kiểm tra container đã chạy
docker ps
```

### 1.2 Kiểm tra GPU availability
```bash
# Kiểm tra CUDA có sẵn trong container không
docker exec chatbot-backend python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'N/A')"

# Kiểm tra GPU usage
nvidia-smi
```

### 1.3 Nếu GPU không hoạt động
```bash
# Kiểm tra Docker có hỗ trợ GPU không
docker info | findstr -i runtime

# Rebuild image với GPU support
docker compose -f docker-compose_gpu.yml build --no-cache backend

# Restart containers
docker compose -f docker-compose_gpu.yml up -d
```

## 2. Xóa Index Cũ

### 2.1 Xóa toàn bộ collection (bao gồm index và data)
```bash
# Xóa collection diagnostic support
docker exec chatbot-backend python -c "
from pymilvus import connections, utility
connections.connect(host='milvus-standalone', port='19530')
if utility.has_collection('mental_health_diagnostic_support'):
    utility.drop_collection('mental_health_diagnostic_support')
    print('✅ Deleted mental_health_diagnostic_support')
"

# Xóa collection treatment guidance
docker exec chatbot-backend python -c "
from pymilvus import connections, utility
connections.connect(host='milvus-standalone', port='19530')
if utility.has_collection('mental_health_treatment_guidance'):
    utility.drop_collection('mental_health_treatment_guidance')
    print('✅ Deleted mental_health_treatment_guidance')
"
```

### 2.2 Xóa file skip IDs (để ingest lại từ đầu)
```bash
# Xóa file skip của diagnostic support
docker exec chatbot-backend rm -f data/processed/mental_health_diagnostic_support_ids_embedded.txt

# Xóa file skip của treatment guidance
docker exec chatbot-backend rm -f data/processed/mental_health_treatment_guidance_ids_embedded.txt

# Verify đã xóa
docker exec chatbot-backend ls -la data/processed/
```

### 2.3 Xóa tất cả collections trong Milvus
```bash
docker exec chatbot-backend python -c "
from pymilvus import connections, utility
connections.connect(host='milvus-standalone', port='19530')
collections = utility.list_collections()
for col in collections:
    utility.drop_collection(col)
    print(f'✅ Deleted {col}')
print(f'Total deleted: {len(collections)} collections')
"
```

## 3. Tạo Index Mới

### 3.1 Ingest Diagnostic Support (1,772 records)
```bash
# Với GPU (nhanh, khuyến nghị)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_diagnostic_support \
  --batch 256 \
  --drop

# Nếu GPU không hoạt động (CPU, chậm hơn)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_diagnostic_support \
  --batch 32 \
  --drop
```

**Thời gian ước tính:**
- GPU (RTX 4060): ~3-5 phút
- CPU: ~40-60 phút

### 3.2 Ingest Treatment Guidance (4,143 records)
```bash
# Với GPU (nhanh, khuyến nghị)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_treatment_guidance \
  --batch 256 \
  --drop

# Nếu GPU không hoạt động (CPU, chậm hơn)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_treatment_guidance \
  --batch 32 \
  --drop
```

**Thời gian ước tính:**
- GPU (RTX 4060): ~8-10 phút
- CPU: ~100-130 phút

### 3.3 Ingest Normal Responses (226 records)
```bash
# Với GPU (nhanh, khuyến nghị)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection normal_responses \
  --batch 256 \
  --drop

# Nếu GPU không hoạt động (CPU, chậm hơn)
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection normal_responses \
  --batch 32 \
  --drop
```

**Thời gian ước tính:**
- GPU (RTX 4060): ~1-2 phút
- CPU: ~5-10 phút

**Note:** Collection này chứa responses cho normal stress và adjustment reactions (không phải mental disorder).

### 3.4 Parameters giải thích
- `--collection`: Tên collection cần ingest
- `--batch`: Số records xử lý cùng lúc (GPU: 256-512, CPU: 32-64)
- `--drop`: Xóa collection cũ trước khi tạo mới (optional)

## 5. Troubleshooting

### 5.1 GPU không được sử dụng
**Triệu chứng:** `Using device: cpu` trong logs

**Giải pháp:**
1. Kiểm tra NVIDIA Docker runtime:
```bash
docker info | findstr -i runtime
```

2. Kiểm tra GPU drivers:
```bash
nvidia-smi
```

3. Restart Docker Desktop và thử lại

4. Nếu vẫn không được, sử dụng CPU mode với batch size nhỏ hơn

### 5.2 Out of Memory (OOM)
**Triệu chứng:** Container crash hoặc `CUDA out of memory`

**Giải pháp:**
```bash
# Giảm batch size
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_diagnostic_support \
  --batch 64  # Giảm từ 256 xuống 64
```

### 5.3 Connection timeout đến Milvus
**Triệu chứng:** `MilvusException: Fail connecting to server`

**Giải pháp:**
```bash
# Kiểm tra Milvus container
docker ps | findstr milvus

# Restart Milvus nếu cần
docker compose -f docker-compose_gpu.yml restart milvus-standalone

# Đợi 10-15 giây cho Milvus khởi động
timeout /t 15

# Thử lại ingestion
```

### 5.4 Ingestion bị stuck
**Triệu chứng:** Không có output trong vài phút

**Giải pháp:**
```bash
# Kiểm tra logs
docker logs chatbot-backend -f

# Kiểm tra CPU/Memory usage
docker stats chatbot-backend

# Nếu cần, stop và restart
docker compose -f docker-compose_gpu.yml restart backend
```

### 5.5 Skip file không được tạo
**Triệu chứng:** Ingestion process ingest lại records đã có

**Giải pháp:**
```bash
# Kiểm tra quyền ghi
docker exec chatbot-backend ls -la data/processed/

# Tạo directory nếu không tồn tại
docker exec chatbot-backend mkdir -p data/processed/

# Chạy lại ingestion
```

## 6. Quick Commands Reference

### Full Reset & Re-Index (GPU)
```bash
# 1. Stop all containers
docker compose down

# 2. Start with GPU
docker compose -f docker-compose_gpu.yml up -d

# 3. Wait for services
timeout /t 15

# 4. Delete all data
docker exec chatbot-backend python -c "from pymilvus import connections, utility; connections.connect(host='milvus-standalone', port='19530'); [utility.drop_collection(c) for c in utility.list_collections()]"
docker exec chatbot-backend rm -f data/processed/*_ids_embedded.txt

# 5. Ingest diagnostic support
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index --collection mental_health_diagnostic_support --batch 256 --drop

# 6. Ingest treatment guidance
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index --collection mental_health_treatment_guidance --batch 256 --drop

# 7. Ingest normal responses
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index --collection normal_responses --batch 256 --drop

# 8. Verify
docker exec chatbot-backend python check_collections.py
```

### Incremental Index (tiếp tục từ skip file)
```bash
# Chỉ ingest records chưa được process
docker exec chatbot-backend python -m src.rag.ingestion.vectors.index \
  --collection mental_health_treatment_guidance \
  --batch 256
```

### Monitor Ingestion Progress
```bash
# Terminal 1: Watch logs
docker logs chatbot-backend -f

# Terminal 2: Watch collection count (chạy mỗi 10 giây)
while ($true) { 
    docker exec chatbot-backend python check_collections.py 
    Start-Sleep -Seconds 10 
}
```

## 7. Best Practices

### ✅ DO:
- Sử dụng GPU compose khi có RTX 4060 để tăng tốc 20-30x
- Set batch size = 256 hoặc 512 với GPU
- Kiểm tra GPU availability trước khi ingest
- Backup skip files trước khi xóa
- Monitor memory usage trong quá trình ingestion
- Verify số lượng entities sau mỗi lần ingest

### ❌ DON'T:
- Không sử dụng batch size quá lớn (>512) → OOM
- Không restart container giữa chừng ingestion → mất progress
- Không xóa skip file nếu chỉ muốn ingest thêm records mới
- Không chạy 2 ingestion process song song trên cùng collection
- Không quên restart backend sau khi ingestion xong để clear cache

## 8. Performance Benchmarks

| Collection | Records | GPU (RTX 4060) | CPU (Intel i7) | Speed Up |
|------------|---------|----------------|----------------|----------|
| Diagnostic Support | 1,772 | ~3-5 min | ~40-60 min | **~15x** |
| Treatment Guidance | 4,143 | ~8-10 min | ~100-130 min | **~12x** |
| Normal Responses | 226 | ~1-2 min | ~5-10 min | **~5x** |
| **Total** | **6,141** | **~12-17 min** | **~145-200 min** | **~12x** |

**Batch size impact (GPU):**
- Batch 64: ~18-25 min total
- Batch 128: ~15-20 min total
- Batch 256: ~12-17 min total ✅ **Recommended**
- Batch 512: ~10-15 min total (risk OOM)
